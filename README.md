# Табло Печалба

Уеб приложение за телефона, което чете рекламните ти акаунти в Мета и смята оборот, печалба, ROAS, POAS и CPA.

## 1. Вземи токен от Мета (веднъж)

1. business.facebook.com → Настройки → Потребители → **Системни потребители** → Добави (роля „Служител“).
2. **Присвояване на активи** → Рекламни акаунти → избери Bio и Словения → право „Преглед на ефективността“.
3. Настройки → Акаунти → **Приложения** → Добави → Създай ново приложение с цел „Реклами чрез Marketing API“, свързано с бизнеса. Присвои го на системния потребител.
4. Върни се на системния потребител → **Генериране на нов токен** → избери приложението → изтичане „Никога“ → отметни само **ads_read** → Генерирай.
5. Копирай токена. Не го пращай по имейл или в чат.

## 2. Качи приложението (безплатно)

1. Разархивирай zip файла.
2. Отвори https://app.netlify.com/drop, влез или си направи безплатен акаунт.
3. Провлачи папката `tablo-app` в полето. След секунди получаваш адрес като `нещо.netlify.app`.
4. В Netlify: Project configuration → General → смени името на проекта (напр. `tablo-mitko`), за да е лесен адресът.
5. Ако сайтът иска парола или вход: Project configuration → Access & security → Visibility → направи го публичен. Данните ти не са в сайта, а само в телефона ти заедно с токена.

## 3. Инсталирай на телефона

- **iPhone (Safari):** отвори адреса → бутон Сподели → „Добави към началния екран“.
- **Android (Chrome):** отвори адреса → меню ⋮ → „Инсталирай приложението“.

Отвори иконката „Табло“ → Настройки → постави токена → „Запази и провери“ → задай себестойност на поръчка.

## Обновяване на приложението

Когато получиш нова версия, провлачи новата папка в Netlify → Deploys. Настройките и корекциите на телефона остават.

## Важно

- Настройките и корекциите се пазят в браузъра на телефона. За пренос на друго устройство ползвай Настройки → Архив.
- Ако Мета спре версията на API (съобщение в приложението), смени я в Настройки → Разширени.
